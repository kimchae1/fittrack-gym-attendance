FITTRACK — GYM ATTENDANCE MANAGER
1. Extract this ZIP.
2. Open the extracted folder in VS Code (File > Open Folder).
3. Open index.html and choose "Open with Live Server", or double-click index.html in File Explorer.
Includes add member, check-in/check-out, inside/outside counts, search, status filter, remove member, unique-ID validation, business-rule validation, and localStorage persistence.
The hero background image uses an online Unsplash URL; internet is needed to load that image. App functionality runs in the browser.
